`npm run check` is the required project gate. The verified movement slice has fake-based adapter and task lifecycle tests; live Minecraft, Discord, and provider connections remain untested. `npm audit` previously reported zero vulnerabilities after pinning transitive `uuid` to the patched 11.x line.

### Resource collection decision (2026-10-26)

The published `mineflayer-collectblock@1.6.0` and `mineflayer-tool@1.2.0` are MIT-licensed and their declared Mineflayer/Pathfinder ranges include Sena's resolved Mineflayer 4.39.0 and Pathfinder 2.4.5. This establishes declared version-range compatibility only, not a live integration pass. npm metadata declares no Node engine for either package. The repository heads advertise unpublished 1.7.0/1.3.0 versions, so those APIs are not treated as the released artifacts. Collection remains disabled: published collectblock code weakens two pathfinder movement guards and its cancellation primitive only stops pathfinding while the collection routine may still be mining or waiting for drops. A future integration needs a cancellation contract that safely interrupts digging and proves plugin-owned movement settings cannot override Sena's policy. No packages were installed for this audit.
